Website informasi & promosi lahan strategis di sekitar kawasan IKN Nusantara, Penajam Paser Utara, Kalimantan Timur — dikelola oleh **BTN Nusantara Land**.

## Isi Website
- Detail spesifikasi lahan (luas, harga, status Hak Milik, koordinat lokasi)
- Informasi tentang perkembangan IKN Nusantara
- Potensi investasi lahan di sekitar kawasan IKN
- Kontak langsung (WhatsApp & Email)

## Cara Menjalankan Secara Lokal
Cukup buka file `index.html` langsung di browser — tidak perlu server atau instalasi apapun.

## Cara Deploy ke GitHub Pages
1. Buat repository baru di GitHub bernama `nusantara-land-listing`
2. Upload/push semua isi folder ini ke branch `main`
3. Masuk ke **Settings > Pages** pada repo
4. Di bagian **Source**, pilih branch `main` dan folder `/ (root)`
5. Simpan — GitHub akan memberi link publik seperti:
   `https://<username-github>.github.io/nusantara-land-listing/`
6. Tunggu 1–2 menit, lalu buka link tersebut untuk melihat website live
